Introducción

En este sitio web se presenta un análisis detallado sobre los conocimientos técnicos expuestos en el material audiovisual del trabajo práctico, abarcando desde conceptos fundamentales hasta la aplicación práctica en el área del desarrollo web.

Conceptos fundamentales

  • Arquitectura de software: Organización y estructura lógica del proyecto.
  • Sintaxis: Reglas gramaticales de un lenguaje de programación o marcado.
  • Despliegue: Proceso de publicar una aplicación web para ser accesible en internet.
  • Depuración: Proceso de encontrar y corregir errores en el código.
  • Responsividad: Capacidad de la interfaz para adaptarse a pantallas móviles y de escritorio.

Cuestionario resuelto

  1. ¿Cuál es el tema principal del video?
    Trata sobre las técnicas y herramientas clave para la estructuración y optimización de proyectos web.
  2. ¿Qué problema o necesidad tecnológica se aborda?
    La necesidad de organizar, desarrollar y publicar sitios web de manera eficiente y libre de errores.
  3. ¿Cuáles son los cinco conceptos más importantes?
    Estructura, Sintaxis, Despliegue, Depuración y Responsividad.
  4. ¿Qué herramientas, programas o tecnologías se mencionan?
    Editores de código (VS Code), HTML5, CSS3, plataformas de alojamiento web (GitHub Pages/Netlify).
  5. ¿Qué procedimientos o pasos se explican?
    1. Configuración del entorno. 2. Maquetación del código. 3. Estilizado CSS. 4. Pruebas. 5. Publicación en la nube.
  6. ¿Qué ejemplos prácticos aparecen?
    El paso a paso para estructurar una página responsiva y desplegarla públicamente.
  7. ¿Qué conocimientos previos son necesarios?
    Nociones de computación, lógica básica y manejo de editores de texto.
  8. ¿Qué ventajas o beneficios ofrece la tecnología o procedimiento?
    Automatización, velocidad de trabajo, mantenimiento accesible y presencia global en la web.
  9. ¿Qué dificultades, errores o precauciones deben considerarse?
    Verificar las rutas relativas de imágenes/estilos y probar el sitio sin iniciar sesión.
  10. ¿Cómo aplicarías lo aprendido en un proyecto informático real?
    Creando sitios de información, catálogos o portafolios web bien estructurados.
  11. ¿Qué parte del video consideras más importante y por qué?
    El despliegue del sitio, ya que permite llevar un proyecto local a un entorno público real.
  12. ¿Qué conocimientos nuevos adquiriste y cómo los explicarías?
    El proceso de alojamiento web; lo explicaría como subir un archivo público que cualquiera puede consultar con un enlace.

Aplicación práctica

A través de la elaboración de esta misma página web, he aplicado los conceptos de maquetación HTML5 semántica y diseño CSS adaptable. El procedimiento incluyó la creación local de archivos, el diseño visual mediante reglas CSS y la posterior publicación en un servidor de hosting accesible públicamente.

Conclusión personal

El desarrollo de este trabajo práctico permitió reforzar habilidades clave en el diseño de interfaces web responsivas y el uso de plataformas de alojamiento online. Estos conocimientos resultan fundamentales para mi formación técnica en informática y futuros proyectos profesionales.
